
# Pica breathing star

© 2026 Anna Elize de Heer. All rights reserved.

Pica Breathing Star is a personal breathing and focus app designed to guide mindful sessions through a rotating star rhythm and room-based breathing states.

## Purpose
This app supports a calming daily breathing ritual using:
- a visual star-based breathing guide
- Soul, Mind, Heart, Strength based focus states
- session timing
- progress tracking for meditation minutes and goal completion

## Features
- 4 breathing room states
- visual star animation
- timer countdown
- box-breathing cycle
- meditation and goal tracking sliders
-  calming interface
